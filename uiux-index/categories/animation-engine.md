### [Animista](https://animista.net/)

### [Easings.net](https://easings.net/)

- tags: js, timeline, scrolltrigger, industry-standard

### [Lenis](https://lenis.darkroom.engineering/)

### [LottieFiles](https://lottiefiles.com/)
- tags: after-effects, json-animation, lottie-player

### [Motion (Framer Motion)](https://motion.dev)
- tags: js, react, spring-physics, layout-animation
- npm `motion` (wraps framer-motion); spring transforms, layout animation, scroll-linked motion, gestures. Vendored: component-source/js-animation-engines/motion.js

### [Principle](https://principleformac.com/)
- tags: mac-app, paid, interaction-prototyping
- paid Mac app for timeline/state-based interaction prototyping, common for handoff-quality motion specs

### [ProtoPie](https://www.protopie.io/)
- tags: no-code, sensor-input, interaction-prototyping
- no-code interaction prototyping tool, supports sensor/device input triggers beyond click/hover

### [Rive](https://rive.app/)
- tags: interactive, state-machine, runtime, design-tool
- design tool + lightweight runtime for interactive vector animations with state machines (hover/drag-reactive, not just timeline playback)

### [Spline](https://spline.design/)
- tags: 3d, webgl, design-tool, real-time
- real-time 3D design tool for building interactive WebGL scenes without hand-writing Three.js

### [Splitting.js](https://splitting.js.org/)
- tags: text-split, css-vars, kinetic-type, vendored
- splits text/grid DOM into per-character/word spans with CSS custom-property indices, for kinetic-type and stagger effects — MIT, vendored at component-source/splitting/

### [Theatre.js](https://www.theatrejs.com/)
- tags: js, visual-editor, precise-keyframing
