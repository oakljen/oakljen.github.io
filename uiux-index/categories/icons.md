# icons

### [Feather Icons](https://feathericons.com/)
- tags: svg, minimal, mit
- minimal open-source icon set, predecessor lineage to Lucide

### [Font Awesome](https://fontawesome.com/)
- tags: icon-font, svg, freemium
- long-standing icon font/SVG set, free tier + paid pro set

### [Heroicons](https://heroicons.com/)
- tags: svg, tailwind-team, mit
- MIT icon set by the Tailwind team. Vendored: component-source/icons/heroicons

### [Iconoir](https://iconoir.com/)
- tags: svg, mit, open-source
- open-source icon library, react/vue/svelte packages available

### [Lucide](https://lucide.dev/)
- tags: svg, open-source, react
- ISC-licensed icon set, fork of Feather. Vendored: component-source/icons/lucide

### [Phosphor Icons](https://phosphoricons.com/)
- tags: svg, 6-weights, mit
- MIT (@phosphor-icons/core), 6 style variants x ~1500 icons — fetch per-icon rather than pre-vendoring the whole set

### [Remix Icon](https://remixicon.com/)
- tags: svg, neutral-style
- neutral-style open-source icon set

### [Simple Icons](https://simpleicons.org/)
- tags: brand-logos, svg
- free SVG brand/logo icons for popular products and services

### [Tabler Icons](https://tabler.io/icons)
- tags: svg, large-set, mit
- large free MIT icon set (5000+), consistent stroke style
