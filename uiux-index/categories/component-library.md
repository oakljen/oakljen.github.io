# component-library

### [21st.dev](https://21st.dev/)
- tags: marketplace, shadcn-registry, react
- marketplace of many authors' shadcn-registry components, discovery/inspiration only

### [Aceternity UI](https://ui.aceternity.com/)
- tags: react, tailwind, framer-motion, decorative
- copy-paste snippets/shadcn-registry entries, no single clonable repo — inspiration-only

### [Ark UI](https://ark-ui.com/)
- tags: headless, state-machines, multi-framework
- headless component library built on statecharts (Zag.js), framework-agnostic logic

### [Chakra UI](https://www.chakra-ui.com/)
- tags: react, accessible, theming
- accessible React component library with a style-prop theming system

### [Cult UI](https://cult-ui.com)
- tags: react, tailwind, motion, shadcn-cli, set-piece
- niche animated shadcn-CLI components (Dynamic Island widget, direction-aware tabs) not covered by kokonutui/magicui — MIT, vendored

### [daisyUI](https://daisyui.com/)
- tags: tailwind, css-only, themeable
- CSS-class component library on top of Tailwind, no JS required, many built-in themes

### [Flowbite](https://flowbite.com/)
- tags: tailwind, react, vue, svelte
- open-source Tailwind component library + Figma UI kit

### [Headless UI](https://headlessui.com/)
- tags: react, vue, unstyled, tailwind-team
- unstyled accessible components from the Tailwind team, pairs with Tailwind CSS

### [HeroUI (NextUI)](https://www.heroui.com/)
- tags: react, tailwind, react-aria, apache-2.0
- Apache-2.0 (not MIT despite site claims), React-Aria-based a11y patterns — reference only, not vendored (npm-only, no copy-paste files)

### [KokonutUI](https://kokonutui.com)
- tags: react, tailwind, motion, shadcn-cli
- MIT (kokonut-labs/kokonutui). Vendored: action-search-bar, attract-button, bento-grid, card-flip, file-upload, glitch-text, liquid-glass-card, mouse-effect-card

### [Magic UI](https://magicui.design)
- tags: react, tailwind, motion, marketing
- MIT (magicuidesign/magicui). Vendored: border-beam, marquee, shimmer-button, dock

### [Mantine](https://mantine.dev/)
- tags: react, hooks, forms, dates
- full React component + hooks library, strong forms/dates/notifications modules

### [OriginKit](https://www.originkit.dev)
- tags: react, decorative-effects, glass, glow, tilt, bento
- free animated component library; MCP plugin fetches source via API + key. Vendored: blackhole.tsx, smokytext.tsx

### [Park UI](https://park-ui.com/)
- tags: ark-ui, tailwind, panda-css, multi-framework
- components built on Ark UI, ships for React/Vue/Solid with Tailwind or Panda CSS styling

### [Radix UI](https://www.radix-ui.com)
- tags: primitives, accessible, aria, unstyled, react
- unstyled accessible primitives + Themes 12-step color scale + Icons; the rigor reference for keyboard/ARIA contracts. Vendored: component-source/radix-primitives, component-source/radix-colors

### [React Bits](https://www.reactbits.dev/)
- tags: react, animation, decorative
- real repo DavidHDev/react-bits, MIT + Commons Clause — do NOT vendor/bundle, read+adapt per-project only

### [shadcn/ui](https://ui.shadcn.com/)
- tags: react, tailwind, radix, copy-paste
- MIT, Tailwind-styled wrappers around Radix primitives; copy-paste CLI-installed components

### [shadcn/ui MCP](https://ui.shadcn.com/docs/mcp)
- tags: mcp, registry-search, ai-tool
- official MCP server to search/install shadcn-registry components via natural language — documented in uimaxing/mcp-servers.md

### [Tailwind UI](https://tailwindui.com/)
- tags: tailwind, paid, marketing, application-ui
- official paid Tailwind component/template set from Tailwind Labs

### [Uiverse](https://uiverse.io/)
- tags: css, tailwind, community, snippets
- huge community library of copy-paste CSS/Tailwind buttons, cards, loaders, checkboxes
