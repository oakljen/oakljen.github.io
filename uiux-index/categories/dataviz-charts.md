# dataviz-charts

### [ApexCharts](https://apexcharts.com/)
- tags: js, interactive, free
- free interactive JS charting library, wide chart-type coverage

### [bklit](https://bklit.com/)
- tags: react, charts, monochrome-accent
- design-engineered chart set (17+ types), restrained neutral+one-accent palette model. Vendored: component-source/bklit-ui (technique reference, not standalone-runnable)

### [Chart.js](https://www.chartjs.org/)
- tags: js, canvas, lightweight
- lightweight canvas-based charting library, the common default

### [Nivo](https://nivo.rocks/)
- tags: react, d3, svg-canvas-webgl
- React data-viz components with SVG/Canvas/WebGL render targets

### [Observable Plot](https://observablehq.com/plot/)
- tags: js, grammar-of-graphics, concise
- concise grammar-of-graphics charting library from the D3 team

### [Recharts](https://recharts.org/)
- tags: react, d3-based, composable
- composable React charting library built on D3 primitives

### [Tremor](https://tremor.so/)
- tags: react, dashboard, tailwind, charts
- React library specifically for dashboards/charts, Tailwind-based

### [visx](https://airbnb.io/visx/)
- tags: react, d3, low-level, airbnb
- Airbnb's low-level React viz primitives built on D3, for fully custom charts
